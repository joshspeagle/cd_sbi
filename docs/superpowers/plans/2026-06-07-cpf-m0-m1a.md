# CPF — M0 → M1a TDD implementation plan

**Spec:** `docs/superpowers/specs/2026-06-07-conformal-pivot-flow-design.md`
**Scope:** M0 (validity skeleton, no flow, global conformal, `LocationNormal1D`) → M1a (no-`Î`
kill-or-confirm, `NormalUnknownMeanVar`). **M1b / M2 / the local-Mondrian partition / external
baselines are OUT of scope here** (separate plan, post-M1a).
**Discipline:** strict TDD — write the failing test, then the code. Three disjoint sim splits.
Coverage is reported only from the audit split. `pip install -e ".[dev]"`; `pytest` for fast tests,
`pytest -m intensive` for the replications.

> **Why this scope:** M0 needs only Small/Medium pieces and certifies the validity machinery in
> isolation; M1a is the cheap decisive experiment that gates the whole direction (spec §11 GATE 1).
> No triangular inversion, no partition, no external method builds — those are M1b/M2.

## M0 — validity skeleton

### Step 1 — RNG streams `flow/cal/audit`
- **Code:** `reproducibility/seeding.py` — extend `SeededRNGs` (currently `train/eval/init`) with
  `flow`, `cal`, `audit` derived via the existing `_derive(master, label)` helper. Keep `train/eval/
  init` for back-compat.
- **Test** (`tests/unit/test_seeding_cpf.py`): the three new streams are deterministic from the
  master seed, pairwise distinct, and draws from `flow`/`cal`/`audit` are disjoint (no shared
  samples) for a fixed master seed. Re-seeding reproduces them bit-identically.

### Step 2 — `ConformalPivotProcedure`
- **Code:** a new procedure delegating to `confidence_set/procedures.py::CriticalValueProcedure` with
  `test_stat_fn = lambda θ,x: F̂_{T|θ}(T(θ;x))` and `critical_value_fn = lambda θ,α: q̂_α` (a
  **constant** in θ; `CriticalValueProcedure.contains_batch` already handles scalar `c_val.ndim==0`).
  The set is `{θ : F̂(T(θ;x)) ≤ q̂_α}` = super-level set of `H=1−F̂`.
- **Test** (`tests/unit/test_conformal_pivot_procedure.py`): on a hand-built monotone `F̂` and
  constant `q̂_α`, set membership matches the closed-form super-level set; sets are **nested in α**
  (non-crossing) for a grid of α; 1D `confidence_set` boundary matches the analytic threshold.

### Step 3 — isotonic monotone-α head
- **Code:** a post-hoc rearrangement wrapper over `methods/lf2i.py::MultiQuantileMLP` outputs
  (Chernozhukov–Fernández-Val–Galichon): sort the per-α quantile predictions to enforce monotonicity
  in α. No architecture change.
- **Test** (`tests/unit/test_isotonic_alpha_head.py`): feed deliberately **crossing** quantile rows;
  after rearrangement, `q(α)` is monotone in α for every input row (non-crossing fraction ≡ 0); the
  rearrangement is idempotent and preserves the marginal quantile levels.

### Step 4 — global split-conformal recalibration of `H`
- **Code:** `methods/cpf/conformal.py` — on calibration pairs `(θ_j,x_j)`, score
  `s_j = F̂_{T|θ_j}(T(θ_j;x_j))`; `q̂_α =` the `⌈α(n+1)⌉/n` empirical quantile of `{s_j}`. The set is
  `{θ : F̂_{T|θ}(T(θ;x)) ≤ q̂_α}`. This is the **single global α-relabeling map** (coherence-preserving).
- **Test** (`tests/unit/test_global_conformal.py`): on exchangeable synthetic scores `s_j ~ U[0,1]`,
  empirical marginal coverage of `{s ≤ q̂_α}` is `≥ 1−α` and `≤ 1−α + 1/(n+1)` across α and n; a
  deliberately-wrong `F̂` (constant) inflates the set (wider) but does **not** drop below `1−α`
  coverage (the "degrades to wider, never under-covers" property).

### Step 5 — `evaluate_coverage` adapter for an `H`-field
- **Code:** `diagnostics/engine.py::evaluate_coverage` has a hardwired 3-way dispatch
  (`has_pivot`→χ²-on-`‖r‖²`; `has_stat`→`T≤c_α`; else `contains_batch`). Add a **4th branch** (or an
  explicit adapter) so a `ConformalPivotProcedure` is evaluated as `test_statistic = F̂(T(θ;x))`,
  `critical_value ≡ q̂_α`. Note: the pivot χ²-KS / per-coord-PIT diagnostics do **not** auto-fire for
  this branch (they assume `‖r‖²`); CPF's PIT diagnostics come from Step 8.
- **Test** (`tests/diagnostics/test_engine_cpf_branch.py`): on a closed-form `H`-field, the new
  branch's coverage table is **bit-identical** to a hand-computed reference; chunk-invariance holds.

### Step 6 — M0 integration on `LocationNormal1D` (the milestone)
- **Code:** wire Steps 1–5: `T = ‖r_star‖²` (closed-form pivot from the simulator), fit `F̂_{T|θ}` by
  quantile regression **on θ** on split B, global conformal, `ConformalPivotProcedure`, audit on split
  C. Recover the `N(x,σ²)` CD.
- **Tests** (`tests/integration/test_cpf_m0.py`):
  - **pivot KS:** `H(θ₀;x)|θ₀` is `U[0,1]` (KS vs U) → equivalently the pivot KS vs `N(0,1)`.
  - **coverage:** `coverage_error_max` (per-θ₀ grid, swept α) within the χ² noise floor.
  - **coherence:** non-crossing fraction ≡ 0 **after both** the isotonic and conformal layers (not
    just pre-conformal).
  - **NEGATIVE CONTROL (per-θ₀ conditional, mandatory):** a miswired calibrator that conditions `F̂`
    on `x` (a summary) instead of θ must **fail a per-θ₀ conditional KS** (or a coverage-vs-θ₀ slope
    test) at a pre-registered threshold — while the correct θ-conditioned calibrator passes. Assert
    that a *pooled/marginal* PIT does **not** distinguish them (documents why the marginal test is
    insufficient).

**M0 done when:** all Step-6 tests pass on `LocationNormal1D`.

## M1a — no-`Î` kill-or-confirm (`NormalUnknownMeanVar`)

### Step 7 — `ConformalPivotFlowRunner` + persistence
- **Code:** `methods/cpf/runner.py` — a 3-stage `fit()` (TwoStageCDSBIRunner pattern): train flow
  (split A, NF-MLE, no `Î`) → freeze → fit `F̂` + conformal (split B) → audit (split C). **Persistence
  (spec §4.6):** write flow + conditioner `state_dict` to disk (the in-memory `state_dict` already
  exists, `methods/base.py:17`, `methods/cd_sbi.py:189`; only the disk write at `run.py:635` is
  missing) under a **versioned** format; keep the metadata-only loader
  (`analysis/figures/data_io/checkpoints.py:30-39`) working; serialize the calibration head +
  conformal scores; record `{seed,label}` provenance per stage.
- **Tests** (`tests/unit/test_cpf_runner_persistence.py`):
  - `assert_disjoint(provenance_A, draw_B)` **raises** on an overlapping draw (the firewall guard).
  - checkpoint round-trips (flow + conditioner + calibrator) and reproduces the same `H`/sets.
  - an old metadata-only checkpoint still loads (back-compat).

### Step 8 — sampler draw-and-PIT diagnostic
- **Code:** draw `θ ~ H(·|x)` via `flows/invert.py::autoregressive_invert` (single-index flow), then
  PIT the draws. **New diagnostic path** — the existing μ-CD recovery
  (`marginal_cd_recovery.py::_marginalize_mu`) uses finite-difference marginalization, **not**
  inversion; this draws-and-PITs the *sampler*.
- **Test** (`tests/diagnostics/test_cpf_sampler_pit.py`): on `NormalUnknownMeanVar`, draws from `H`
  pass a PIT KS on the σ²-direct (χ²) marginal; the draw↔set consistency check (a draw falls in `C_α`
  with prob ≈ 1−α) holds.

### Step 9 — M1a integration (GATE 1)
- **Code:** full no-`Î` CPF on `NormalUnknownMeanVar`, three splits, persistence, audit.
- **Tests** (`tests/intensive/test_cpf_m1a.py`, `@pytest.mark.intensive`):
  - **GATE 1:** `coverage_error_max ≲ 0.03` AND sampler PIT KS ≤ 0.05 on **both** σ²-direct (χ²) and
    μ-marginalized (**Student-t**) CDs (μ-marginalized via the draw-and-PIT path of Step 8).
  - **leak audit, two arms:** an **A→B** run (reuse flow data for calibration) **and** a **B→C** run
    (share calibration/locale draws with the audit) each show **≥ a pre-registered δ** under-coverage
    vs the clean three-split run; if indistinguishable, the test fails as **underpowered** (raise n).
- **GATE 1 decision:** if the no-`Î` calibrator cannot recover the Student-t → `Î` was load-bearing
  *for power*; reintroduce `Î` and re-scope (spec §11). Record the verdict in
  `docs/notes/2026-..-cpf-m1a-verdict.md`.

**M1a done when:** the intensive test clears GATE 1 (or cleanly fails it, recording the `Î` verdict).
